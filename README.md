# FakeLoc

基于 **LSPosed / libxposed API 101** 的虚拟定位模块。不需要开发者选项里的「模拟位置」，
也不需要 root 去改系统设置 —— 直接接管位置读取路径：除了系统的 `android.location`，
还会接管**目标 App 自己内嵌的高德 / 百度 / 腾讯定位 SDK**，覆盖那些完全不读系统定位的 App。

选点页用**腾讯地图**：拖图钉、搜地址、点图反查。

## 功能

| 功能 | 说明 |
|---|---|
| 在地图上选点 | 腾讯底图，拖图钉 / 搜地址 / 点图反查，选完统一换算成 WGS-84 |
| 坐标输入 | 纬度 / 经度，六位小数；**不做坐标系换算**，输入什么就是什么 |
| 常用坐标 | 八个内置城市，点击即设为锚点 |
| 使用真实定位 | 以当前位置为起点（需要定位权限，受 5 秒节流保护） |
| 粘贴解析 | 从剪贴板识别坐标、Google 地图链接、`geo:` URI、`?lat=&lng=` 参数 |
| 生效范围 | 作用域内全部应用，或只对勾选的那几个 |
| 信号微调 | 精度 / 海拔 / 速度 / 步行漂移（在设置页的「信号微调」页签） |
| 假地址 | 城市 / 省 / 区跟着假坐标走（系统 `Geocoder` 反查），可单独关掉 |
| 反检测 | 抹掉 `isFromMockProvider` / `isMock` / AppOps / SettingsProvider 的 mock 标记；可**锁定原始定位源**（切断 WiFi 扫描、基站信息与原始 GNSS）—— 这是「地图先跳到模拟点、几秒后又跳回真实位置」的正解 |

## 使用方法

### 1. 安装

从 [最新 Release](https://github.com/Cobylinweiqi/FakeLoc/releases/latest) 下载
`FakeLoc-<版本>-release.apk`，或在 LSPosed 管理器的「在线仓库」里搜 **FakeLoc** 直接装。

包名是 `io.github.cobylinweiqi.fakeloc`。APK 用本项目专用密钥签名，**自己编译出来的包签名不同，
两者不能互相覆盖安装** —— 更新请始终走 Release。更早的 `com.amo.fakeloc` 是另一个 App，
如果你装过，需要先卸载。

### 2. 在 LSPosed 里激活

1. **启用 FakeLoc** 模块
2. **配置作用域**（这一步决定它到底管不管用）：
   - 默认的 `android` 与 `com.android.providers.settings` 负责反检测的全局部分，建议保留
   - 再把你想要伪造定位的 App 逐个勾上
3. 重启设备，或至少重启目标 App
4. 打开 App，界面顶部不再显示「未连接到 LSPosed 服务」即表示握手成功

> **只勾目标 App 时，Google Play 服务的融合定位（fused）拿到的仍是真坐标** —— 那个位置是 GMS
> 在自己进程里算出来的。两个解法任选：把 `com.google.android.gms` 也加进作用域（轻量，推荐先试）；
> 或者打开「系统级 hook」并把 `system` 加进作用域（覆盖最广，代价是作用域内所有 App 都被改写）。

> 「生效范围」名单只决定**谁收到假位置**，模块本身还得在 LSPosed 作用域里 —— 两者是**与**的关系。

### 3. 配置地图 Key（可跳过）

选点页的底图是腾讯地图，**包里不含任何 Key**，需要你自己去
[腾讯位置服务](https://lbs.qq.com) 申请（免费额度够个人使用），再填进 App 的**设置页 → 地图配置**。
申请时控制台要填的**包名与 SHA-1**，App 设置页里都显示着，各带一个复制按钮 —— 直接复制，别手抄。
（官方 Release 的证书 SHA-1 是 `28a3a1d6f8a0d9b00af1a33a70586cc0c20a04b0`，自编译的包不一样。）

**不填 Key 也能用**：手动输入坐标、粘贴解析、内置城市都不受影响，只是选点页没有底图。

### 4. 用起来

底部主按钮启动 / 停止，运行中也能改参数。首页状态卡上的三个 chip 显示当前的精度 / 海拔 / 漂移值。

**锁定定位源**（默认开）会切断目标 App 的 WiFi 扫描、基站信息与原始 GNSS。带着自研引擎的 App
（高德这类）靠它才能被挡住「自己再算一个真实位置」这条路。代价是那个 App 失去基于 WiFi / 基站的
室内定位能力 —— 如果它因此报「定位失败」，把这个开关关掉即可。

### 5. 已知限制

- **反检测不等于隐身。** 它只抹掉 mock 标记；做多源交叉验证的 App（真 GPS 与网络定位对不上、
  传感器与轨迹不符）仍可能看出异常。
- **原始 NMEA / GNSS 观测数据**只在系统级作用域开启时才被压制。只勾目标 App 时，
  `addNmeaListener` 之类仍能拿到与假坐标矛盾的真实卫星数据。
- **Wi-Fi / 基站指纹完全没做** —— 要对抗基于 BSSID 的定位，那部分得自己加。
- **`system` 作用域下是本机全量伪造**，包括 FakeLoc 自己的「使用真实定位」按钮。
- 功能开关只在运行中的进程生效，**新增作用域内的 App 需要重启目标 App** 一次。
- 选点页**需要联网**（底图瓦片走 HTTPS，地址查询走系统 `Geocoder`）。
